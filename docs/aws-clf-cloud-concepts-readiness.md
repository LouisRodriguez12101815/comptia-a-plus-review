# AWS CLF-C02 Domain 1 readiness slice

This change follows the merged Domain 4 work in PR #222 and targets Cloud Concepts objectives 1.1 and 1.4.

## Changes

- Added `q-clf11-13` for applying scalability and multi-AZ availability to a planned-growth scenario.
- Added `q-clf14-15` for migration TCO, including transfer, dual-running, training and licensing costs.
- Added `q-clf14-16` for separating committed baseline spending from variable usage.
- Strengthened the existing benefits lesson with an operational-efficiency guard: managed services reduce selected undifferentiated work but do not remove customer configuration, data, access, recovery or cost responsibilities.
- Added semantic answer-key and answer-position regression coverage for all new questions.

Existing Domain 1 lessons and questions already cover elasticity, agility, scalability, global reach, availability/resilience, managed services, CapEx/OpEx, rightsizing, economies of scale, licensing and TCO. Objective statuses remain `partial`; this slice adds application scenarios without claiming complete exam coverage.

## Scope and limitations

The new questions use the repository’s official CLF-C02 Domain 1 mapping and AWS exam-guide URL. Live AWS documentation retrieval was unavailable in this environment, so no current guide revision date is asserted. No UI, persistence, Network+, SAA-C03, localization or deployment configuration was changed.
