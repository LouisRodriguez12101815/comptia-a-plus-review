# AWS source authority policy

Checked: 2026-11-06
Exam: AWS Certified Cloud Practitioner (CLF-C02)
Exam guide: version 1.3, October 29, 2026

## Authority order

1. The current AWS Certified Cloud Practitioner exam guide, domain pages, revision history, and in-scope service list control exam scope, task statements, terminology, and domain weights.
2. Current AWS service documentation controls technical behavior and service terminology.
3. Uploaded books, slides, class notes, labs, and historical exam guides are teaching/reference material only.
4. Practice-question material is useful for identifying tested concepts and distractor patterns, but it is not an authority and must not be copied.

The current scope references are recorded in [`content/aws-review-sources.json`](../content/aws-review-sources.json). The current in-scope service source is the AWS CLF-C02 in-scope service list linked there.

## Freshness and stale-source handling

Before adding or expanding CLF-C02 content, recheck the current AWS exam guide and in-scope service list. A source that predates the checked guide version remains historical evidence and must not override current AWS scope. Flag retired, renamed, or changed services in the reconciliation document; make a learner-facing correction only when the current AWS source clearly establishes it.

The uploaded CLF-C02 Exam Guide version 1.0 and older instructional support-plan tables are not current scope authorities. The repository's existing Snowball Edge/Snowcone qualification is retained as historical/current-service context and is not an invitation to expand stale material.

## Original content rule

Future questions must be written originally. Do not copy or lightly paraphrase AWS or third-party practice questions, answer choices, or explanations. Use external material only to choose concepts and verify facts, then write new scenarios and explanations with traceable current sources.
