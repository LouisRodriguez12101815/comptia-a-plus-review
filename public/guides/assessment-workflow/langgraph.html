Checks that matter

    Selected stage · not a live execution state

    Coverage is an evidence claim

    A named term, an explanation, and an unresolved retrieval gap are different outcomes. A missing answer or unavailable source stays unresolved; it does not become an absent lesson.

    Measurement is a separate step

    The graph prepares a reproducible blinded sample. Agreement is calculated only after reference labels come back. Another model’s agreement is not a measured human error rate.

    The site stays separate

    Assessment outputs belong to the new tool. This graph has no stage that edits lessons, commits changes, pushes code, or publishes a website.
