Chapter 10 Protocol Map

Routing protocols grouped by level. Start with what a protocol is for, then how it learns routes. Tap any protocol for details.

Availability

Keeps a default gateway reachable when a device fails

First-hop redundancy

Hosts point at one virtual gateway that moves between routers.

Routing

Learns and chooses paths to remote networks

Distance-vector

Passes routing tables to neighbors and picks by hop count or metric.

Hybrid

Distance-vector at heart, with link-state features.

Link-state

Builds a map of the network and computes best paths from it.

Path-vector (exterior)

Routes between autonomous systems on the Internet.

IPv6 and transition

Discovery and running IPv4 and IPv6 together

Discovery

How IPv6 devices find neighbors and the gateway.

Coexistence

Ways IPv6 traffic crosses or sits beside IPv4.

Administrative distance (AD) ranks route sources: static 1, EIGRP internal 90, IGRP 100, OSPF 110, RIP 120. Lower wins. Connected interfaces use 0.
