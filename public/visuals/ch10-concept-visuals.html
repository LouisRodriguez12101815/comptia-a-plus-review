Protocol families: what each router knows

The type decides how much a router knows about the network. Distance-vector routers only learn routes from neighbors. Link-state routers build a full map.

Distance-vector

RIP, IGRP

Sends its routing table to neighbors. Learns routes secondhand and never sees the whole network. No topology map.

Link-state

OSPF, IS-IS

Every router learns the state of every link. Each builds the same topology map, then runs Dijkstra for best paths.

Hybrid

EIGRP

Distance-vector behavior with link-state features. Keeps a topology table of its own.

Path-vector

BGP

Routes between autonomous systems and tracks the path of AS numbers, not the internal topology.

Why RIP is the answer to Q6: RIP has no topology table. It only trusts what its neighbors tell it. The number 15 is RIP's hop limit, not the number of routers it sends updates to.

Administrative distance: which source wins

When two sources offer the same route, the router picks the source with the lowest administrative distance (AD). The AD measures how much the router trusts that source.

Pick two sources to see which one the router installs.

Metrics: how each protocol measures a path

The metric is the protocol's own cost for a path. Protocols can't compare metrics with each other, which is why AD exists.

RIP

Hop count

Counts routers crossed. 1 to 15 is usable, 16 is unreachable.

OSPF

Cost

Reference bandwidth (100 Mbps) divided by the interface bandwidth. Faster links cost less.

EIGRP

Composite

Combines delay, bandwidth, reliability, and load. K values weight each part.

Remember: a metric only compares routes from the same protocol. AD compares routes from different protocols.

Routing loops and TTL

A loop forms when routers pass a packet back and forth and never deliver it. Each router decreases the TTL by one, and the packet is discarded when TTL reaches 0.

Symptom to look for: the packet keeps circling until its TTL expires. It never reaches the destination. Packets that take a long path or come back on a different interface are not loops.

Static, default, and dynamic routing: what happens on a failure

Pick a routing method, then break the link. Watch who has to fix the route.

Dynamic: routers recalculate and move traffic to the backup path on their own. Static: the route stays as typed until an administrator changes it. Default routes also need manual changes if they fail.

IPv6 discovery and transition

IPv6 uses NDP and router advertisements to find neighbors and the gateway. Transition methods let IPv6 and IPv4 coexist.

NDP

Neighbor Discovery

Finds neighboring devices and their information on an IPv6 network.

RA

Router Advertisement

Routers announce themselves so hosts can detect the gateway.

Dual stack

Both at once

The device runs IPv4 and IPv6 side by side and uses whichever the destination supports.

Tunneling

IPv6 in IPv4

IPv6 packets are wrapped inside IPv4 to cross an IPv4-only network. Teredo and ISATAP are tunneling methods.
