Before and during the move

Planning questionRecognition cue
What must be known before moving?Discover applications, dependencies, utilization, data, network relationships, and business criticality.
Which resource moves databases?AWS Database Migration Service supports migration/replication; it is not a strategy and does not prove compatibility.
Which resource moves servers?AWS Application Migration Service supports server/application migration.
What happens before cutover?Validate application behavior, data integrity, dependencies, security, and business acceptance; define rollback.
