File system and partition style lab

Choose the partition style or file system for each drive from the drop-down lists, the way a simulation question gives you a configuration screen. This is practice in the style of a performance-based question, not a copy of a real exam item, and finishing it is not a readiness score.

You are preparing drives for several computers and users. For each drive, choose the partition style or file system that fits the operating system and the way the drive will be used.
