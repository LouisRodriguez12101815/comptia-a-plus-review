Port security limits devices on a port

Port security restricts a switch port to a set number of MAC addresses. This port is limited to two. Connect devices in order and watch which ones are allowed.

Devices (click to connect or disconnect)

Review questions 6 and 13. Port security guarantees a maximum number of devices, either learned or preconfigured. It should be set on an access port. On a trunk, many MAC addresses cross the link, so it is not effective. 802.1X controls who can connect and jumbo frames change frame size, so neither limits the device count.
