Key idea. The IP packet keeps the same source and destination addresses from end to end. Only the frame is rebuilt at each hop, so the destination MAC is always the next device on the local network, here the default gateway on the way out. Frames are never placed on a remote network. A bigger network repeats the same steps with more hops.
