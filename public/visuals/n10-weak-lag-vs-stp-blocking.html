Spanning tree blocks redundant links; a bundle uses them all

Four 1 Gbps links join two switches. Spanning tree keeps one and blocks the rest. Bundle them into one link aggregation group and all four work.

Rules to keep. A designated port forwards for its segment; the root port faces the root bridge; an alternate port is blocked as a backup. A link aggregation bundle looks like one logical link, so spanning tree does not block its members.
