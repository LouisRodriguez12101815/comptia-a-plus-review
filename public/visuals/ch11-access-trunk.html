Access ports, trunk ports, and the native VLAN

An access port connects one end device to one VLAN. A trunk carries many VLANs between switches by tagging frames. Step through a frame to see where the tag is added and removed.

Scenario

Review questions 12, 17, and 19. The access port removes the VLAN ID before the frame leaves, so the client never sees the tag. Only untagged traffic on a trunk is placed on the native VLAN.
