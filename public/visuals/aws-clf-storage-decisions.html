RequirementRecognition cue
Objects and static assetsS3
Frequent/infrequent/archive accessS3 storage classes
Age-based transition or expirationS3 Lifecycle
Persistent EC2 blockEBS
Temporary local blockInstance store
Shared file systemEFS / FSx
On-premises plus AWS storageStorage Gateway
Centralized backup policiesAWS Backup

Lifecycle is not backup, replication is not a tested restore, and instance store is not persistent storage.
