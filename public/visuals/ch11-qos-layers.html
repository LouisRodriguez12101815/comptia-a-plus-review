Which QoS marking works at which layer?

Pick a marking method to see its layer and field. A CoS value is a priority marking, not a universal hardware queue number; queue mapping depends on the device and policy.

Method

Layer 2: Ethernet frame with an 802.1Q tag

Layer 3: IP packet header

CoS value (3 bits, eight priority values)

Marking is not queue count. CoS is a Layer 2 marking with eight possible values. ToS/DiffServ markings are in the Layer 3 IP header. Hardware queue counts and mappings are platform-specific. Source: Cisco Catalyst 2960-CX/3560-CX QoS guide, Restrictions for QoS. N10-009 1.2 / 2.2 supporting context.
