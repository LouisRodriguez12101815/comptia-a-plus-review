WEP, WPA2, WPA3 and enterprise mode

Pick a protocol to see what it is built on and the attack it does or does not stop.

Rules to keep. WEP is RC4 and obsolete. WPA2 is AES with CCMP. WPA3 replaces the shared-key handshake with SAE. Enterprise mode authenticates each user with 802.1X and a RADIUS server. The WPS PIN method can be brute-forced.
