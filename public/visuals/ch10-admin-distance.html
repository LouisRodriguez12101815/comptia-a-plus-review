Administrative distance: which route the router trusts

The same destination can be learned from more than one source. The router compares administrative distance (AD) first. Metrics only break ties between routes from the same protocol.

Rule: lower AD wins, even when the other route has a better metric. The router installs only the winning route in its table.

Question 8 answer is B. ADs define the reliability of each routing source. They don't define standards, calculate shortest paths, or get set for path selection by the router itself.
