SOHO network path and client settings

Illustrative household topology. A modem, ONT, router, firewall, switch, access point and DHCP/DNS functions may be separate devices or combined; the ISP handoff and actual service determine the design.

Text equivalent

  1. Confirm physical link or wireless association and the selected SSID/security mode.
  2. Check address and subnet mask or prefix, then confirm the lease source (DHCP or documented static settings).
  3. Test the default gateway, then name resolution through the configured DNS resolver, then the intended application.
  4. Record the first failing stage. Each symptom narrows the search but does not prove one root cause.
