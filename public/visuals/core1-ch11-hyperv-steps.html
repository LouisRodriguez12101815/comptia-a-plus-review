Enable Hyper-V in Windows 11

For 220-1201 objective 4.1. Check the requirements first, enable the feature second, restart last. Hyper-V is built into Windows as an optional feature, so there is nothing to download.

Step 1 of 6:

    Trap: the CPU setting is virtualization (Intel VT-x or AMD-V), not VT-c. VT-c is a network-I/O feature. Without the setting turned on, the Hyper-V box is missing or VMs will not start.

    Check these first

    Check the edition, CPU and RAM. Two settings are turned on in BIOS/UEFI: hardware virtualization and hardware DEP.

    • Windows 11 Pro or Enterprise. Home cannot run Hyper-V.
    • 64-bit CPU with SLAT.
    • Hardware DEP (Intel XD / AMD NX) turned on in BIOS/UEFI.
    • At least 4 GB RAM.
    • Hardware virtualization (Intel VT-x or AMD-V) turned on in BIOS/UEFI. This is the setting the firmware screen above shows.
