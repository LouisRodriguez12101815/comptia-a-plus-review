Compute and scaling decisions

Match the workload requirement to the service role. Orchestration, compute, capacity and traffic distribution are different decisions.

Need VM control?
→ EC2
Need an event-driven function?
→ Lambda
Need Kubernetes?
→ EKS
Need AWS container orchestration?
→ ECS
Need containers without server management?
→ Fargate
Need changing capacity?
→ Auto Scaling
Need traffic distribution?
→ Load balancer
Need an EC2 resource category?
CPU → compute optimized
Memory → memory optimized
Local I/O → storage optimized

Do not collapse the layers

Confusion pairDistinction
ECS vs EKSECS is AWS container orchestration; EKS is managed Kubernetes.
