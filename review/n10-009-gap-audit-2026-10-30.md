# Network+ N10-009 gap audit (2026-10-30)

Source of truth: CompTIA Network+ N10-009 Exam Objectives v4.0 (PDF Louis supplied). Exam in about 7 days. Max 90 questions, 90 minutes. Weights: 1.0 Concepts 23%, 2.0 Implementation 20%, 3.0 Operations 19%, 4.0 Security 14%, 5.0 Troubleshooting 24%.

## Method
Every leaf bullet in the official objectives (404 items) was turned into a keyword pattern and searched in the site's Network+ notes, flashcards and questions (topics tagged n10-009: 24 topics, 385 questions, 223 flashcards). Heuristic: a keyword miss can be a wording difference, so each gap needs a quick check when its content is written.

Result: 88 of 404 official bullets (22%) have no match anywhere on the site. About 100 more have no Network+ question or flashcard but match content in another track (Core 1, Core 2, AWS), so they need adapting or tagging, not new teaching.

## Site bug: objective numbering
Official 3.3 = Disaster recovery, 3.4 = IPv4 and IPv6 network services (DHCP, DNS, NTP), 3.5 = Network access and management methods. The site's content/objectives.json has them as 3.3 network services, 3.4 access and management, 3.5 disaster recovery. Fix the ids and titles so the coverage page and test mode match the real exam.
